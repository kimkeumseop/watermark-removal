워터마크 제거 사용 안내

어떤 파일에 맞는지 먼저 확인하고, 결과를 저장하기 전에 미리보기를 살펴보세요.

먼저 알아둘 점

클린프레임은 선택한 사각형 안의 원본 픽셀을 복원하는 도구가 아닙니다. 영역 주변의 색과 무늬를 참고해 안쪽을 다시 채웁니다. 하늘·벽·단색 배경처럼 주변이 고르면 자연스럽지만, 얼굴·글자·촘촘한 무늬 위에서는 번짐이나 자국이 남을 수 있습니다. 제거 영역을 꼭 필요한 만큼만 작게 잡고 결과를 확대해 확인하는 편이 좋습니다.

본인이 소유하거나 수정 권한이 있는 파일에만 사용하세요. 다른 사람의 저작권 표시를 지워 사용할 권한이 생기는 것은 아닙니다.

고정된 영상 워터마크 처리

영상 도구 열기. 먼저 브라우저에서 재생되는 영상 파일을 고릅니다. 영상이 뜨면 미리보기 재생 또는 처음으로 버튼으로 워터마크가 처음부터 끝까지 같은 위치에 있는지 살펴보세요. 이 도구는 선택한 위치를 영상 전체에 적용하므로, 화면 안에서 움직이는 로고에는 맞지 않습니다.

  • 워터마크를 둘러싸듯 드래그하되 인접한 사람이나 글자가 들어가지 않도록 범위를 좁힙니다. 떨어진 표시가 여러 개면 영역을 각각 추가할 수 있습니다.
  • 잘못 지정했으면 해당 영역을 지우거나 전체 선택을 초기화한 뒤 다시 지정합니다.
  • 워터마크 제거를 누르면 브라우저에서 모든 프레임을 다시 인코딩합니다. 완료 후 결과 영상을 재생해 처음·중간·끝 부분의 자국을 확인하고 MP4로 저장합니다.

영상은 파일 크기뿐 아니라 재생 시간과 해상도에 따라 메모리를 많이 씁니다. 200MB를 넘으면 경고가 나오며, 긴 고해상도 영상은 브라우저가 멈추거나 처리에 실패할 수 있습니다. 이 경우 짧은 구간으로 나누거나 해상도를 낮춘 사본으로 먼저 시험해 보세요. 입력 영상 코덱이 브라우저에서 재생되지 않으면 파일을 선택해도 미리보기가 열리지 않을 수 있습니다.

이미지 한 장 또는 폴더 처리

이미지 도구 열기. 한 장만 처리할 때는 이미지 선택 버튼으로 JPG·PNG·WEBP 파일을 고릅니다. 이미지 위에서 제거할 부분을 드래그한 뒤 처리하고, 화면의 전후 비교에서 자국을 확인하세요. 한 장의 결과는 ZIP이 아니라 이미지 파일 하나로 내려받습니다.

여러 장은 폴더 선택 또는 끌어놓기로 불러옵니다. 첫 이미지를 대표로 영역을 지정하면 그 위치를 가로·세로 비율로 기록해 나머지 이미지에도 적용합니다. 예를 들어 대표 이미지의 오른쪽 아래에 있던 고정 로고라면 해상도가 다른 이미지에서도 비슷한 위치에 적용됩니다. 다만 사진마다 로고 위치나 크기가 달라지면 같은 비율을 적용해도 엉뚱한 부분이 지워질 수 있습니다. 일괄 처리 전에 대표 이미지와 다른 몇 장을 비교하고, 처리 후 ZIP 안의 결과를 표본 확인하세요.

JPG는 다시 저장할 때 손실 압축이 적용될 수 있고, 투명한 PNG·WEBP는 주변 픽셀에 따라 경계가 달라 보일 수 있습니다. 여러 장의 결과는 원래 파일명과 폴더 구조를 유지한 ZIP에 담기지만, 대량의 고해상도 이미지는 브라우저 메모리와 저장 공간을 많이 사용합니다.

결과가 만족스럽지 않을 때

  • 지운 자리가 뿌옇다면 영역을 더 작게 잡거나 배경이 단순한 장면으로 시험합니다. 이 방식은 가려진 원본 내용을 추측해 되살리지 않습니다.
  • 영상 처리가 시작되지 않으면 페이지를 새로 열고 브라우저가 영상 처리 엔진을 불러오는지 확인합니다. 첫 실행에는 큰 처리 파일을 내려받으므로 연결 상태의 영향을 받습니다.
  • 완료 전에 탭을 닫으면 브라우저 메모리에 있던 작업은 사라집니다. 결과를 받은 뒤에는 다운로드 파일을 직접 열어 정상 재생·표시되는지 확인하세요.

파일 처리 자체는 브라우저 안에서 이루어집니다. 사이트 접속 및 광고 관련 데이터 처리 범위는 개인정보처리방침에서 확인할 수 있습니다.
