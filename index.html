FAQ

자주 묻는 질문

영상이 서버로 올라가나요?

올라가지 않습니다. 파일을 고르면 브라우저 메모리에서만 읽고, 제거 작업도 브라우저 안에서 실행되는 ffmpeg.wasm이 처리합니다. 네트워크로 나가는 영상 데이터는 없습니다.

워터마크는 어떤 방식으로 지워지나요?

지정한 사각형 영역을 ffmpeg의 delogo 필터가 처리합니다. 영역 테두리 바깥의 픽셀을 참고해 안쪽을 다시 채우는 방식이라 배경이 단순할수록 자연스럽고, 무늬가 복잡한 배경 위에서는 흐릿한 자국이 남을 수 있습니다.

어떤 파일 형식을 지원하나요?

브라우저가 재생할 수 있는 MP4, MOV, WEBM 등을 불러올 수 있습니다. 결과물은 MP4로 저장됩니다. 영상이 길거나 해상도가 높으면 브라우저 메모리를 많이 쓰기 때문에 처리 시간이 길어집니다.

움직이는 워터마크도 지울 수 있나요?

위치가 고정된 워터마크에 맞춘 도구입니다. 화면 안에서 움직이는 워터마크는 지정한 영역을 벗어나는 순간 다시 보이게 됩니다.

처리 시간이 오래 걸리는데 정상인가요?

정상입니다. 서버 대신 본인 기기의 CPU가 모든 프레임을 다시 인코딩합니다. 처리 중에는 탭을 닫거나 다른 영상을 올리지 말고, 노트북이라면 전원을 연결한 상태로 두는 편이 빠릅니다.
